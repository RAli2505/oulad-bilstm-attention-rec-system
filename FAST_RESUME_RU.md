# Ускоренное продолжение полной системы

4 ноября 2026 года подготовлена отдельная оптимизация исполнения. Исходные recommendations/sequential.py, full_agent_experiment.py и run_oulad_agent_experiment.py не изменены. Старые контрольные точки сохраняются и проверяются исходным механизмом восстановления.

Оптимизация заменяет создание отдельной pandas-таблицы на каждый день истории одним проходом по отсортированным строкам обучающегося. Группировка, суммы, порядок токенов, скалярный log1p, ограничения истории, префиксы и режим обучения сохранены. Новая реализация подключается только в ускоренном процессе. Её контрольная сумма и отчёт проверки записываются отдельно как execution_acceleration_*.json; исходный manifest не выдаётся за единственный источник кода ускоренного исполнения.

На 48 историях обучающихся 2013 года (11497 строк до дня 98) получено точное совпадение последовательностей и обучающих префиксов. Дополнительно проверены объединённая история нескольких обучающихся, пустая история, неизвестные ресурсы, дубли и исключение cutoff. Три повторных замера в последней серии: медиана 2.745 с против 1.667 с, ускорение участка 1.65 раза. В предыдущей серии при другой нагрузке выигрыш составлял 3.80 раза. Полное ускорение эксперимента не измерено; указанные числа относятся только к построению последовательностей.

Проверка диспетчера выполнена с отключённым вызовом обучения. Полное обучение при подготовке не запускалось, процессы не останавливались. Test 2014 не оценивался.

Команда использует Python 3.12, UTF-8 и сохранённые параметры, включая CUDA:

```powershell
rtk proxy powershell -NoProfile -ExecutionPolicy Bypass -File "./resume_full_agent.ps1"
```

При уже работающей полной системе не запускать второй процесс. Для применения нового варианта потребуется завершение либо прерывание текущего процесса пользователем и повторный запуск. Завершённые день/seed используются повторно, незавершённый день/seed архивируется исходным механизмом и начинается заново. Сохранение каждой эпохи исходной полной системы не предусмотрено.

Для исходного исполнения без новой оптимизации:

```powershell
rtk proxy powershell -NoProfile -ExecutionPolicy Bypass -File "./resume_full_agent.ps1" -Original
```

Отчёт проверки: ../tmp/fast_full_agent_validation/report.json. При изменении ускоренного файла или исходных вычислительных модулей проверка устаревает и ускоренный запуск отклоняется. Оригинальные ограничения продолжения по конфигурации и контрольным суммам не отключены.
