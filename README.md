# OULAD: модели прогнозирования и сравнительные эксперименты

**Архив для статьи и диссертации:** [состав, научный статус, восстановление и push через Git LFS](research_archive/README_RU.md). Снимок включает полные файлы трёх исследовательских запусков и исходные CSV; итоговые таблицы доступны без распаковки. Снимок пяти seed содержит только фактически выполненную часть эксперимента.

**Улучшенный эксперимент v2:** запускайте `rtk proxy py -3.12 -X utf8 -u run_improved_article.py`.

Окна: **каждые 7 дней от 7 до 168 включительно (24 окна)**, seed 42, test 2014 отключён. Используется один фиксированный train/validation split 70/30 в 2013 году по ученикам. Исходные 14 методов дополнены четырьмя ансамблями: BiLSTM + LightGBM + Transformer и LSTM + BiLSTM Attention (proposed) + LightGBM, каждый с равными и внутренне подобранными весами. Добавлены поведенческие/календарные признаки и ограниченный подбор параметров на внутренних частях train-пула. Калибровка отделена от выбора параметров. [Протокол v2](docs/IMPROVED_PROTOCOL_RU.md).

Для первого запуска на основном окне добавьте --windows 56. Без этого параметра выполняются все 24 окна; внутренний поиск существенно увеличивает длительность. Старые результаты сохраняются отдельно. Новый протокол требует нового каталога запуска.

**Базовый эксперимент v1 (без улучшенного поиска):** запускайте `rtk proxy py -3.12 -u run_risk_article.py`.
Это единое сравнение 14 моделей, включая Transformer, три абляции и адаптацию модели статьи: окна 28/56/112 дней, пять фолдов по ученикам. Первый этап: seed 42 (210 обучений); остальные seed 13, 7, 23, 101 добавляются позже. Протокол и все сохраняемые характеристики описаны в [docs/RISK_ARTICLE_PROTOCOL_RU.md](docs/RISK_ARTICLE_PROTOCOL_RU.md).

Сохраняются калибровка до/после, train–validation gaps, признаки недостаточной сходимости, кривые обучения, веса, предсказания, точные фолды, характеристики оборудования и все параметры. Внешний test 2014 отключён: используются только обучение и validation/CV 2013. Основной анализ использует наблюдаемые признаки активности/сдач и исключает числовые оценки без timestamp публикации. Полное обучение этим запуском ещё не проводилось.

Самостоятельный исследовательский репозиторий без зависимости от агентов и оркестратора.

**Происхождение сравнительного эксперимента:** `experiments/hybrid-attention` — локальное воспроизведение подхода Omarbekova et al. (2026), *A temporal attention-based hybrid deep learning model for student performance and academic risk prediction*, DOI: 10.3389/frai.2026.1811886. Архитектура BiLSTM + attention + MLP, набор baseline-моделей и схема таблиц заимствованы для воспроизведения; они не заявляются здесь как новая архитектура. Протокол v2 исправляет оценку и сохранение артефактов, но сам по себе не устанавливает научную новизну. `models/pred_oulad.py` представляет отдельный эксперимент с другой целью и BCE + Cox loss.

## Отдельное воспроизведение статьи о прогнозе успешного завершения

```powershell
rtk proxy py -3.12 -u run_article.py
```

Предварительная проверка: `rtk proxy py -3.12 run_article.py --check`.
Дополнительные t-SNE/PCA/UMAP: добавьте `--latent-viz` (по умолчанию эти иллюстрации пропускаются, все обучающие эксперименты выполняются).

Новый протокол v2: разбиения по ученикам, независимый test около 20%, пять групповых CV-фолдов только на development. Нормализация внутри train, включая внутреннюю validation в CV. Для основного обучения и CV задано максимум 100 эпох, patience 7, batch 64. Все модели используют одни и те же внешние фолды. Числа нового протокола не обязаны совпадать с историческими результатами.

Ускорение: данные TensorDataset хранятся на GPU, батчи выбираются одним индексированием вместо обработки отдельных строк; метрики копируются на CPU один раз за оценку, потери — один раз за эпоху. Сохранена FP32 и включены детерминированные операции. Для SVM удалена ненужная внутренняя калибровка вероятностей: ROC-AUC считается по decision_function, классы — по predict. SVM не выдаёт калиброванные вероятности; для Brier/log loss потребуется отдельная калибровка на train.

Вывод: новая папка `runs/<UTC timestamp>/`, которая не перезаписывает исторические результаты. Там сохраняются версии библиотек, контрольные суммы данных/исходников, разбиения, preprocessing фолдов, веса, предсказания и метрики. Фолды имеют отдельные веса, финальные графики используют основную holdout-модель. Подбор по test выполнять нельзя; CV используется для сравнения на development.

**Область научных выводов:** сравнительный pipeline использует агрегаты оценок за курс и длинную историю VLE, исключает Withdrawn и прогнозирует успешное завершение. Это ретроспективная классификация, а не доказательство раннего предупреждения об оттоке. Временные абляции ограничивают только VLE, сохраняя статические признаки; их нельзя представлять как полностью cutoff-safe ранний прогноз. Для раннего прогноза требуется отдельное ограничение всех признаков на момент наблюдения. Категориальные коды сохраняют историческое кодирование; scaler обучается только на fit-части.

## Состав

- `models/pred_oulad.py`: LSTM, BiLSTM + Attention, TCN + BiLSTM + Attention и ансамбли с LightGBM/XGBoost. Динамические признаки объединяются со статическими; обучение использует BCE + Cox loss.
- `results/oulad/pred_metrics*.json`: исходные сохранённые результаты, включая окна наблюдения, абляции и несколько seed.
- `experiments/hybrid-attention/`: отдельный набор сравнительных экспериментов — MLP, Logistic Regression, Random Forest, SVM, XGBoost, LightGBM, нейронная гибридная модель, кросс-валидация и абляции. Сохранены notebook, таблицы и графики.
- `models/oulad_hybrid_attention.py`: адаптер вывода гибридной модели.
- `data/oulad_loader.py`: подготовка OULAD; локальные raw/processed/splits скопированы и исключены из Git.
- `tests/`: перенесённые тесты модели и метрик.
- `docs/migration_manifest.json`: происхождение файлов и SHA-256 до/после переноса.
- `docs/CROSS_VALIDATION_RU.md`: сохранённый протокол 5-fold CV и таблица mean ± std для всех сравнительных моделей.

## Сохранённые результаты

| Вариант | ROC-AUC | PR-AUC | Brier |
|---|---:|---:|---:|
| BiLSTM + Attention | 0.87497486 | 0.83497868 | 0.12910403 |
| LSTM + BiLSTM Attention + LightGBM | 0.87860336 | 0.82281372 | 0.12720563 |

Это исторические метрики, а не результат повторного обучения в новом репозитории. Файлы весов `.pt` для этих запусков в исходном проекте не найдены. Точные настройки старых запусков не полностью записаны в JSON; текущий код мог меняться после их получения.

В `pred_oulad.py` положительный класс объединяет `Fail` и `Withdrawn`: это неуспешное завершение обучения. В `experiments/hybrid-attention` используется отдельный протокол (без Withdrawn, прогноз успеха). Метрики двух протоколов нельзя объединять в одну сравнительную таблицу без согласования выборки, целевой метки и разбиения. Подробности исторического протокола находятся в README эксперимента.

## Запуск из корня репозитория

Python 3.12:

```powershell
rtk proxy py -3.12 -m pip install -r requirements.txt
rtk proxy py -3.12 -m models.pred_oulad --help
rtk proxy py -3.12 -m models.pred_oulad --architecture bilstm_attention --data-dir data/oulad/raw --build --tag new_run
rtk proxy py -3.12 -m pytest tests -q
```

Для ансамбля: `--architecture ensemble`. Для LSTM: `--architecture lstm`. Для TCN: `--architecture tcn_bilstm_attention`. Указывайте новый `--tag`, чтобы сохранить исторические результаты.

Для сравнительных экспериментов установите `requirements-experiments.txt`, перейдите в `experiments/hybrid-attention` и запустите `main.py`. В `config.py` доступны переключатели `RUN_BASELINE_ML`, `RUN_KFOLD`, `RUN_ABLATION`. По умолчанию дорогие блоки отключены; включите нужные для повторного сравнения. Повторный запуск может перезаписать таблицы и графики эксперимента.

Исходные данные: `data/oulad/raw`. Подготовленные таблицы уже находятся в `data/oulad/processed`, разбиения — в `data/oulad/splits`. Они доступны локально, но не попадут в клон Git. Для нового клона поместите CSV OULAD в указанную папку и выполните:

```powershell
rtk proxy py -3.12 -m data.oulad_loader --data-dir data/oulad/raw --build
```

Репозиторий создан локально. Публикация на GitHub не выполнялась.

## Адаптивные рекомендации

`recommendations/` — отдельный рекомендательный модуль поверх готовых
прогнозов ансамбля. Обновляемая модель предпочтений учитывает давность
взаимодействий с конкретными материалами, ограничивает вклад повторных
кликов и сглаживает короткую историю. Ранжирование объединяет предпочтения,
учебный календарь и поведение, используя исходную вероятность риска без
изменения. Код обучения, веса и сохранённые исследовательские результаты
не затрагиваются. Интеграция, запуск и ограничения описаны в
[docs/RECOMMENDATIONS_RU.md](docs/RECOMMENDATIONS_RU.md).

Полный новый запуск прогноза и оценки рекомендаций: `rtk proxy py -3.12 -X utf8 -u run_system_experiment.py`.
Ровно девять окон 7/14/21/28/56/84/112/140/168, один seed 42 по умолчанию, train/validation 2013;
test 2014 отключён. Два исхода обучения (успех/неуспех), PR-AUC, Precision/Recall/F1,
рекомендационные Precision/Recall/NDCG@5/10/20, независимая калибровка,
train gaps, веса, CI, время и память описаны в [протоколе полного эксперимента](docs/SYSTEM_EXPERIMENT_RU.md).
Команда обучает только LSTM, BiLSTM Attention и LightGBM, подбирает веса
их ансамбля и оценивает основной адаптивный рекомендательный модуль.
Остальные сравнительные модели и абляции не запускаются.
Подготовка рекомендационных признаков ускорена пакетным расчётом без
сокращения студентов и кандидатов: [проверки и бенчмарк](docs/BATCHED_FEATURES_RU.md).
