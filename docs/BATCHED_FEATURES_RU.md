# Ускорение подготовки рекомендационных признаков без смены протокола

## Изменение

Профилирование на 48 реальных запросах выявило 96 вызовов observable_context:
каталог и история проверялись дважды для каждого студента. Основное время
занимали повторные pandas merge/groupby и построение индивидуальных объектов.

Новый движок `batched` проверяет каталог один раз для курса и вычисляет
профили/кандидаты пакетами. По умолчанию пакет содержит до 256 запросов.
Это граница промежуточной памяти, **не ограничение числа студентов или кандидатов**.
Все выходные данные остаются в эксперименте. Исходный расчёт сохранён
как `--feature-engine reference` для воспроизведения и сравнения.

Сохранены исходные ключи зачисления и порядок запросов, полный каталог
доступных кандидатов, фильтр недавних просмотров, ограничение дневных кликов,
затухание 14 дней, сглаживание, учёт старых недоступных материалов,
fit-only популярность, временные границы истории и будущих меток.
Размер пакета не участвует в формулах. Веса ансамбля и прогнозирующие
модели не изменяются. Число seed, K и bootstrap-повторов не сокращается.

## Применение к уже обученным моделям

Работающий процесс не меняется от редактирования Python-файла. Для
применения оптимизации пользователь может остановить текущий
рекомендационный этап через Ctrl+C и запустить новый:

```powershell
rtk proxy py -3.12 -X utf8 -u "C:\Users\user\Documents\Diser\система\oulad-bilstm-attention\run_system_experiment.py" --risk-run "C:\Users\user\Documents\Diser\система\oulad-bilstm-attention\runs\risk_20261101T123221178430Z" --seeds 42 --threads 6 --feature-engine batched --feature-batch-size 256
```

Нейросети и LightGBM повторно не обучаются. Рекомендационные признаки
пересчитываются в новом каталоге, с полным составом запросов/кандидатов.
Движок выводит прогресс по числу обработанных запросов.

Для пакетного этапа сохраняются полное время и амортизированная стоимость
на запрос. Отдельные p50/p95 для построения индивидуального профиля имеют
значение null: общую пакетную работу нельзя выдавать за измерение каждого
запроса. Реальные p50/p95/p99 ранжирования продолжают измеряться отдельно.

## Проверки

Тесты сравнивают эталон и пакеты размера 1/5/256 на днях 7/14/56, включая
холодный старт, неизвестные ресурсы, будущую активность, дубли кликов,
истёкшую доступность и ограниченную длительность курса. Проверяются
все признаки с допуском 1e-12 и точное совпадение top-K. Есть проверки
отсутствия мутации входов и утечки будущих кликов.

Полный набор: 113 passed, 15 предупреждений joblib/NumPy, PYTEST_EXIT_CODE=0.
Внешний процесс снова сообщил exit1 после успешного pytest; известное
расхождение окружения сохранено в журнале. Независимый просмотр текущих
файлов не выявил существенных ошибок в протоколе или эквивалентности.
Текущий пользовательский процесс агентом не останавливался и не перезапускался.
