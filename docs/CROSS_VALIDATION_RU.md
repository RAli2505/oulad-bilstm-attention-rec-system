# Сохранённые эксперименты по фолдам

## Новые запуски (протокол v2)

Команда `rtk proxy py -3.12 -u run_article.py` выполняет пять `StratifiedGroupKFold` по `id_student` на development; отдельный holdout test в CV не участвует. Внутренняя validation также отделена по ученикам; scaler обучается только на внутренней fit-части. Все сравнительные модели используют один внешний fold manifest. Максимум эпох для гибридной модели — 100 с patience 7; исторический лимит 30 больше не применяется в новом launcher. Веса и метрики каждого фолда сохраняются отдельно. Новые результаты не являются буквальным повторением исторической таблицы ниже.

## Исторические результаты до исправления протокола

Исторический код находился в `experiments/hybrid-attention/tables.py`, функции `_kfold_classical`, `_kfold_hybrid`, `table3_kfold`; затем исправлен для протокола v2.

Параметры в `config.py`: `KFOLD_SPLITS = 5`, `KFOLD_EPOCHS = 30`, `SEED = 42`. Разбиение: `StratifiedKFold(n_splits=5, shuffle=True, random_state=42)`. Масштабирование выполняется внутри внешнего train-фолда; для гибридной модели из него выделяется 15% на раннюю остановку.

Исходная таблица `experiments/hybrid-attention/tables/table3_kfold.csv` перенесена без изменения:

| Модель | ROC-AUC mean ± std | Weighted F1 mean ± std |
|---|---|---|
| Logistic Regression | 0.8960 ± 0.0023 | 0.8425 ± 0.0045 |
| Random Forest | 0.9293 ± 0.0042 | 0.8701 ± 0.0042 |
| SVM | 0.9093 ± 0.0016 | 0.8646 ± 0.0044 |
| XGBoost | 0.9263 ± 0.0039 | 0.8698 ± 0.0046 |
| LightGBM | 0.9323 ± 0.0044 | 0.8738 ± 0.0042 |
| MLP | 0.9070 ± 0.0030 | 0.8571 ± 0.0051 |
| Proposed Hybrid | 0.9576 ± 0.0035 | 0.9039 ± 0.0071 |

В этом эксперименте лучший средний ROC-AUC у Proposed Hybrid. Таблица показывает исторические результаты; обучение при переносе не повторялось.

Для повторения включите `RUN_KFOLD = True` в `config.py` и запустите `main.py` из папки эксперимента. Этот запуск выполняет также основной эксперимент и может перезаписать исходные таблицы.

Сохранённая реализация записывает агрегированные mean/std, а не отдельные файлы метрик каждого фолда или индексы разбиения. При переносе такие файлы не создавались и результаты не восстанавливались предположениями. Разбиение в этом коде стратифицированное по строкам, не групповое по `id_student`.

Результат AUC 0.87497486 из `results/oulad/pred_metrics_bilstm_attention.json` относится к другому пути обучения в `models/pred_oulad.py`; этот JSON не содержит fold-метрик. В данном пути исходные train/val объединяются, затем выделяется один внутренний monitor holdout, а оценка выполняется на test. Не приписывайте ему 5-fold CV без дополнительных артефактов соответствующего запуска.
