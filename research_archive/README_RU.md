# Материалы статьи и диссертации

Снимок `snapshot_20261101` сохраняет результаты на момент архивирования, а не обещание завершённого исследования. Исходные папки `runs/` остаются на месте и могут продолжать пополняться; снимок автоматически не обновляется.

## Что сохранено

- Полные содержимые трёх исследовательских запусков: базовый пятифолдовый `risk_20261031T132513013959Z`, улучшенный seed 42 `risk_20261031T162709361455Z`, незавершённый еженедельный запуск пяти seed `risk_20261031T191741845697Z`.
- Все фактически существовавшие файлы этих запусков, включая итоговые и промежуточные модели поиска, предсказания, калибраторы, preprocessing, индексы разбиений, обучение, диагностику, графики и журналы. Незавершённые результаты не помечаются как завершённые.
- Манифесты параметров, версии окружения, контрольные суммы исходников и данных, исходный код каждого запуска.
- `environment_freeze_20261101.txt` — полный список пакетов Python 3.12 на момент архивирования; для исторического запуска приоритет имеют его собственные `environment.json` и `run_manifest.json`.
- Семь исходных CSV OULAD для воспроизводимости. Наличие данных 2014 в архиве не означает проведения оценки на test: в исследуемых risk-запусках `evaluate_test=false`.
- Итоговые таблицы каждого окна и отчёты доступны также в `reports/` обычными файлами Git. Исторические результаты исходного эксперимента с AUC 0.87497 находятся отдельно в `results/oulad/`; протоколы различаются.

Архивы разбиты по запускам и окнам и хранятся через **Git LFS**. Для каждого архива имеются список всех файлов с размерами и SHA256 (`*.inventory.json`) и SHA256 самого архива (`manifest.json`). При создании каждый файл был независимо прочитан из ZIP и проверен по SHA256.

## Научный статус

В улучшенном завершённом запуске seed 42 все метрики — validation 2013, фиксированный групповой holdout 70/30. 70% дополнительно разделены на fit, selection и calibration. На дне 112 ансамбль LSTM + BiLSTM Attention + LightGBM достиг ROC-AUC 0.87242; это исследовательская оценка на уже просмотренной validation, а не результат закрытого test. Основная ранняя точка — день 56. Нельзя объединять результаты разных протоколов в одну оценку или приписывать весь выигрыш Cox.

На момент снимка еженедельный запуск пяти seed остановлен. Точный статус и число завершённых заданий записаны в `snapshot_20261101/manifest.json`. Остальные seed/окна и финальная оценка 2014 ещё требуют выполнения. Завершённые задания остаются пригодны для анализа; неполные окна нельзя выдавать за полные пять seed.

Диагностика переобучения, калибровка, время выполнения и GPU allocated/reserved сохранены там, где их измерял pipeline. Пиковая RAM CPU и отдельная задержка inference не измерялись: их нельзя восстановить достоверно из архивов. Это не заменяет дополнительные эксперименты по survival-baselines и вкладу Cox в ансамбль.

## Клонирование и будущий push

На машине должен быть установлен Git LFS. После клонирования:

```powershell
rtk git lfs install --local
rtk git lfs pull
```

Remote пока не настроен. После создания своего репозитория один раз добавьте его адрес:

```powershell
rtk git remote add origin "АДРЕС_ВАШЕГО_РЕПОЗИТОРИЯ"
rtk git push -u origin HEAD
```

Установленный локальный LFS pre-push hook отправляет архивы вместе с push. На принимающем сервере нужны поддержка Git LFS и достаточная квота хранилища/трафика. Один только обычный ZIP репозитория с сайта или клон без загрузки LFS содержит указатели вместо содержимого архивов. Не удаляйте локальную копию до проверки удалённой.

## Восстановление конкретного запуска

После `git lfs pull` распакуйте **все** ZIP из `snapshot_20261101/artifacts/ИМЯ_ЗАПУСКА/` в `runs/ИМЯ_ЗАПУСКА/`, сохраняя внутренние пути. `metadata.zip` содержит корневые файлы и снимок кода, остальные ZIP — папки `day_*`. Используйте новую пустую целевую папку или отдельный клон: не перезаписывайте более свежие результаты старым снимком. `oulad_raw.zip` распаковывается в `data/oulad/raw/`.

Для продолжения остановленного запуска с совместимым исходным кодом и окружением:

```powershell
rtk proxy py -3.12 -X utf8 -u run_improved_article.py --seeds 42 13 7 23 101 --resume runs/risk_20261031T191741845697Z
```

Незавершённая модель обучится заново; завершённые задания будут проверены и пропущены. Исходные параметры менять нельзя. Проверка совместимости контролирует код, данные, версии библиотек и конфигурацию устройства.

## Следующий снимок

После новых завершённых экспериментов создавайте новый каталог, не меняя старый снимок:

```powershell
rtk proxy py -3.12 -X utf8 -u tools/archive_research.py --destination research_archive/snapshot_НОВАЯ_ДАТА
rtk git add research_archive
rtk git commit -m "data: archive updated research artifacts"
```

Архивируйте остановленный процесс или завершённый запуск. Скрипт проверяет изменение каждого файла во время копирования, но не заменяет остановку обучения для согласованного снимка всего запуска.
