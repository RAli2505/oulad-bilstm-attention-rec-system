# Полный рекомендательный агент OULAD

Обучены SVD retrieval, daily-basket SASRec и согласование кандидатов; исходный ансамбль риска только прочитан.

Использованы learner-disjoint fit/selection/calibration/held 2013; 2014 не используется. Полная доступная вселенная включает полезные повторы. Эталон исключает недавно просмотренное, но оценивается на той же полной целевой релевантности.

C выбирается только по selection NDCG@10 при Recall@10 не ниже эталона; при отсутствии допустимого варианта сохраняется fallback. MMR=.8 и SASRec=.05 зафиксированы заранее. Отдельная contextual probability head обучена только на calibration и не меняет ранжирование.

ranking_summary.csv содержит P/R/F1/NDCG/MAP/MRR/HitRate @5/10/20. В day_*/seed_* сохранены learner-cluster bootstrap, охват, задержки, память, калибровка, разрывы fit/held, полные признаки, веса и загружаемый agent_bundle. Проверяйте fallback и degenerate_probability.
